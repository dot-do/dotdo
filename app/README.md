# @dotdo/app

Static TanStack Start application for dotdo.

## Features

- TanStack Start for full-stack React
- fumadocs for documentation
- @mdxui/do admin portal
- Dual-mode: REST API or TanStack DB

## Routes

- `/` - Home
- `/admin` - Admin portal
- `/docs` - Documentation
